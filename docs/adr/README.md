# Architecture Decision Records

One file per significant technology or design decision, numbered
`ADR-000N-short-title.md`. Includes the spec §2 scope calls (single-AWS-account
v1, OPA over Sentinel, Azure designed-not-built) and later choices (Pod
Identity over IRSA, Kyverno over Gatekeeper, etc.) — written when each
decision is actually made, not backfilled at the end.

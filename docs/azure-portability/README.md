# Azure portability

The AWS→Azure control mapping table and the ADR explaining what changes
to run this platform on Azure instead — AKS/EKS, ACR/ECR, Key Vault/Secrets
Manager, Entra Workload Identity/Pod Identity, Defender for Cloud/GuardDuty
(spec §2, §7). Designed and documented only — no Azure infrastructure is
deployed in v1. Populated in Phase 10.
